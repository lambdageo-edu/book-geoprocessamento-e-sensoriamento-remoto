    Fontes de Dados Geográficos¶

    Uma das primeiras dificuldades em qualquer projeto de geoprocessamento é encontrar dados confiáveis. Esta página reúne portais brasileiros e internacionais de dados vetoriais e de imagens de sensoriamento remoto. Os endereços mudam com frequência: se algum link estiver quebrado, procure o nome da instituição.

    Antes de usar um dado

    Verifique sempre: a fonte e a data de produção, o sistema de referência (datum e projeção), a escala ou resolução espacial e a licença de uso. Cite a fonte nos seus mapas e trabalhos.
